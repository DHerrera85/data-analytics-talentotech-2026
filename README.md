# Proyecto Integrador de Data Analytics - Talento Tech

Este es mi Proyecto Integrador del curso de Data Analytics del programa Talento Tech 2026. El trabajo desarrolla un proceso de análisis de datos utilizando Python, Pandas y Google Colab.

## Descripción del Proyecto

El proyecto analiza conjuntos de datos de ventas, clientes y campañas de marketing.

A lo largo del notebook se realiza la carga, exploración, limpieza, transformación, agregación e integración de los datos, aplicando los contenidos desarrollados durante el curso.

## Etapas del Análisis

### 1. Recopilación y Preparación de Datos

- Carga de archivos CSV como DataFrames
- Cálculo de ventas mensuales
- Uso de listas y diccionarios para estructurar datos
- Análisis exploratorio inicial
- Identificación de valores nulos y registros duplicados

### 2. Preprocesamiento y Limpieza de Datos

- Eliminación de registros duplicados
- Limpieza de caracteres no deseados
- Conversión de columnas a tipos numéricos
- Tratamiento de valores faltantes

### 3. Transformación de Datos

Se calcula el ingreso total de cada venta y se identifican las ventas de alto rendimiento utilizando como criterio aquellas cuyo ingreso supera el promedio general.

### 4. Agregación de Datos

Las ventas se agrupan por categoría de producto para analizar los ingresos generados por cada categoría.

### 5. Integración de Datos

Se combinan los conjuntos de ventas y marketing mediante la columna `producto`, permitiendo relacionar las ventas con las campañas asociadas.

## Tecnologías Utilizadas

- Python
- Pandas
- Google Colab
- Jupyter Notebook
